# 付费版 —— 已否决（全免费决策记录）

> **决策（2026-08-13）**：不做付费功能，**所有功能全部免费**。本文档只保留决策依据与留档，不再跟踪付费相关工作。

## 决策内容

- v2.0 及后续版本**不设**付费功能：无 Pro、无试用、无免费额度限制、无云同步付费门槛。
- `src/features.js` 的 `PAID_FEATURES` / `tierOf` / `currentPlan` **保留为桩位**（当前 `canUse(*)` 一律返回 `true`，不产生任何限制），仅为未来可能的付费拆分 / 灰度预留，业务代码无需改动。
- 此前讨论过的后端（Supabase / Cloudflare Workers + D1）、收款通道（Paddle / Stripe / Lemon Squeezy / 爱发电）、license 基建、定价、试用期等**全部搁置**，如未来重启付费再行评估。
- 商店描述（`docs/store-assets/descriptions/` 4 份）与隐私政策**不包含任何付费表述**，无需因本次决策改动。

## 为什么否决

- 本项目定位是开发者的免费效率工具，无付费必须项。
- 首发即付费会引入 license 基建、收款合规、客服、退款等大量额外负担，与「先上架验证需求」的目标冲突。
- 扩展 UI 本身零付费入口，保持简洁。
