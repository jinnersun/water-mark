    使用指南

    快速开始

    1. 点击左上角「+」按钮新建一条水印配置
    2. 在「匹配规则」Tab 设置触发条件（域名/URL/IP 等）
    3. 在「外观」Tab 设置水印文字、颜色、字体、透明度等

    匹配规则说明

    • 精确域名：example.com 只匹配完全一致的域名
    • 域名后缀：example.com 匹配所有子域（a.example.com / b.example.com）
    • URL 正则：用正则匹配完整 URL，如 /admin(/.*)?$ 匹配所有 admin 页
    • IP 精确：当网站通过 IP 访问时触发，如 192.0.2.5
    • IP 段 (CIDR)：匹配整个内网网段，如 192.0.2.0/24
    • Cookie：当指定 Cookie 存在或匹配时触发，如 env=prod 或 env~=test

    小提示

    • 每条配置可设置多条规则，任一命中即生效
    • 多条配置命中时，按"最精确优先"原则选择（精确域名 > IP > 正则 > 后缀）
    • 短标签会显示在浏览器工具栏插件图标的右下角，最多 4 个字符
    • 智能对比色会自动根据网页背景反色显示，在深浅背景下都清晰
